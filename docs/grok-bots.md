# Grok Bots Integration

Grok bots provide persistent agents with memory across turns and support for scheduled routines.

## Setup

1. Ensure you have access to Grok bots via your account.
2. Use the bot management tools to create or connect agents.
3. For decision model routing, agents can call System 1 models for fast classification before escalating to full LLMs.

## Example Routine

Schedule periodic checks using bot routines for monitoring or automation.
